# MBTI 테스트 웹사이트

파스텔 톤 디자인의 간단한 4문항 MBTI 테스트입니다. 기존 데스크톱 프로그램의 기본 질문과 결과 계산 방식을 웹에 맞게 옮겼습니다.

## 파일
- `app.py`: Streamlit 웹 앱
- `requirements.txt`: 배포 시 설치할 패키지
- `.streamlit/config.toml`: 테마 설정
- `secrets.toml.example`: 선택 사항인 관리자 비밀번호 설정 예시

## GitHub에 올리고 무료 배포하기
1. GitHub에 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 파일들을 저장소 최상위(root)에 업로드합니다.
3. https://share.streamlit.io/ 에 접속해 GitHub 계정으로 로그인합니다.
4. **Create app**을 선택하고 저장소, 브랜치(`main`), 앱 파일 경로(`app.py`)를 지정합니다.
5. 배포가 끝나면 `https://....streamlit.app` 형태의 주소가 생성됩니다. 그 주소를 다른 사람에게 보내면 됩니다.

## 관리자 비밀번호(선택)
기본 상태에서는 방문자에게 질문 편집 기능이 노출되지 않습니다. 관리자 도구를 사용하려면 Streamlit Cloud 앱 설정의 **Secrets**에 아래와 같이 입력합니다.

```toml
ADMIN_PASSWORD = "여기에_강력한_비밀번호"
```

주의: 관리자 도구에서 수정한 질문은 관리자 본인의 현재 세션에만 적용됩니다. 모든 방문자의 기본 질문을 바꾸려면 `app.py` 상단의 `DEFAULT_QUESTIONS`를 수정한 뒤 GitHub에 다시 올리세요.

## 개인정보 및 결과 저장
이 버전은 이름, 이메일 등 개인정보를 요구하지 않으며 테스트 결과를 데이터베이스에 저장하지 않습니다. 결과는 화면에만 표시됩니다.

## 테스트 결과에 대한 안내
이 앱은 4개 질문으로 결과를 간단히 계산하는 참고용 테스트입니다. 정식 MBTI 검사나 심리 진단을 대신하지 않습니다.
